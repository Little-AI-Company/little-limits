# Repository assets

- `app-icon.png`: 1024 x 1024 PNG. The Paper app icon on the macOS icon grid, and the master for the bundle icon's 64 to 1024 px slots. It is a copy of `branding/app-icon/paper.png`.
- `branding/`: the Little Limits brand: icons, banner, lockups, social image, and the concepts they were chosen from. See [branding/README.md](branding/README.md).
- `screenshots/`: captures of the packaged app for the README and website.
- `design/`: interface concepts generated before Swift implementation. They are not running UI.

## README screenshots

`screenshots/usage-overview.png` and `screenshots/app-settings.png` are Computer captures of the packaged app on October 13, 2026, macOS 27.0.1. Each is 1400 × 1136 pixels, exported as PNG with text/EXIF metadata removed. Image content was not cropped, retouched, or generated. The app source matches `d22cc5a1fdc50229f428802426d708dbfa34afbc`; the captures use the existing connected Claude account rather than demo fixtures. They show the account email and observed subscription quota, with unsupported credit readings still unavailable. Images were inspected for complete rendering and credentials before inclusion. No sign-in, stored balance, or login setting was changed.

The older `screenshots/menu-bar.png` is not used in the README. Native menu capture timed out; no current menu capture is claimed. The README opens with the brand banner, then a capture of the actual Home window.

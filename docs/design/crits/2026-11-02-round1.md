## Verdict

Improvements identified. Eight findings, four at severity 2 and four at severity 1. None blocks a release. Round 1 fixes SETTINGS-01, SETTINGS-02 and SETTINGS-03.

## What a first-time user experiences

The status menu and Home read the same: `17% left, Low`, `0% left, Limit reached`, `Usable in 2d 0h`. With `--demo-states`, the sidebar, the Account Usage table and Weekly Totals agree on every state word, and the grace-period account reads a plain `8% left` with no word, as the doctrine says.

Settings is where the new work lives, and it reads as a list of sentences. Three spots make a person stop. The Burn list label sits beside nothing, with Add Task one line lower (SETTINGS-01). The Copy buttons under AI assistants give no sign that anything happened (SETTINGS-02). The Alerts row reads `Nudge when at least Off of a week would reset unused` until a value is chosen (SETTINGS-06).

## Non-findings

- The grace-period account (`8% left` with no state word) is the documented grace rule, not a missing state.
- Disabled add buttons on the empty page and the disabled Refresh All are demo isolation.
- The sidebar identity line looks dimmer than the quota line in the captures because every capture is of an inactive window; the quota line is set to label color on purpose.

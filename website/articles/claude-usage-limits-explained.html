Claude usage limits explained: the 5-hour and weekly limits

Paid Claude plans have two usage limits: a session limit that resets every five hours, and a weekly limit that resets at a fixed time each week. Claude and Claude Code share both.

Published October 16, 2026 by Parker Rex

Claude usage limits decide how much you can use Claude, Anthropic's AI assistant, before you have to wait. Every plan has a session limit that resets every five hours. Paid plans add a weekly limit on top. Your use of claude.ai, Claude Desktop, and Claude Code all counts toward the same limits (How do usage and length limits work?).

As of October 2026, every fact below comes from Anthropic's own help center, documentation, or pricing page, and each one links to its source. Limits change often, so check the linked page before you rely on a detail. Anthropic publishes no exact message or token counts, so neither does this page.

The 5-hour session limit

The session limit is the short limit. Anthropic's help pages say it "will reset every five hours" (What is the Pro plan?), and the pricing page calls it a "rolling five-hour session window" (Claude pricing). The Free plan has a session limit too.

The official pages do not say exactly when a session window starts. To see when your current one resets, open Settings, then Usage, in Claude.

The weekly limit

The weekly limit is the long limit. On Pro and Max, it "applies across all models" (What is the Max plan?). It resets at a fixed time each week that is assigned to your account (What is the Pro plan?). That reset day and time stay the same no matter when you start using Claude or when your subscription began. For where to find your exact reset times, see when Claude limits reset.

Both limits count your usage at the same time. Anthropic's Claude Code docs warn that one burst of heavy work can use up the weekly limit before the session window resets (Claude Code error reference).

Anthropic also says it may limit usage in other ways, "such as weekly and monthly caps or model and feature usage, at our discretion" (What is the Pro plan?).

Model limits

Some limits apply to one model only. Max plans have a separate weekly limit for Fable, one of Anthropic's model families (Use Claude Code with your Pro or Max plan). The pricing page lists Fable on Max as "50% of weekly limits" and Fable on Pro as available through usage credits (Claude pricing).

Claude Code can also show an Opus limit or a Sonnet limit. Those apply only to that model family, so switching to another model keeps you working. The session and weekly limits are shared across all models, so switching models does not help there.

Claude Pro vs Max limits

Anthropic describes each plan's limits as a multiple of another plan, not as a fixed number:

  • Free: a session limit that resets every five hours.
  • Pro, $20 per month in the US: "at least 5x more usage per 5-hour session than Free", plus a weekly limit (Claude pricing).
  • Max 5x, $100 per month: five times Pro's per-session allowance, plus a weekly limit across all models and the weekly Fable limit above (What is the Max plan?).
  • Max 20x, $200 per month: 20 times Pro's per-session allowance, plus a weekly limit across all models and a weekly Fable limit.
  • Team and Enterprise seats: a per-seat allowance with a five-hour window and a weekly window. Its size depends on the seat tier, Standard or Premium (Manage costs effectively).

The help pages state the Max multiples per five-hour session, not for the weekly limit.

Claude Code usage limits

On Pro and Max, Claude Code does not have its own pool. Activity in Claude and Claude Code "counts against the same limits", and so does use in your IDE (Use Claude Code with your Pro or Max plan). On May 6, 2026, Anthropic doubled Claude Code's five-hour limits for Pro, Max, Team, and seat-based Enterprise, and removed the peak-hours reduction for Pro and Max (Anthropic announcement).

When you run out, Claude Code shows a message with the reset time, such as You've hit your session limit · resets 3:45pm or You've hit your weekly limit · resets Mon 12:00am. Before that, it can warn you, for example at 85% of your session limit.

One trap: if the ANTHROPIC_API_KEY environment variable is set, Claude Code uses that key instead of your subscription, and you pay API charges. Also, the monthly API credits included with Max cannot be used in Claude Code or the Claude apps.

What uses your limits faster

Anthropic lists these factors (Usage limit best practices):

  • Long conversations and large file attachments.
  • Tools such as Research and web search.
  • The model you choose and the effort level.
  • Artifacts and multi-step tasks, such as running code.

In Claude Code, every request sends the full conversation. Long sessions, cache misses after a break of more than an hour, subagents, and scheduled tasks all add up (Manage costs effectively). Starting a fresh session with /clear between unrelated tasks helps.

Usage limits are not the same as length limits. A length limit is the size of the context window in one chat. On paid plans, the newest models support up to 1M tokens (How do usage and length limits work?).

What happens when you hit a limit

You have four options:

  1. Wait. Claude Code can wait in the open session and continue the task after the reset.
  2. Upgrade. A new plan's limits apply right away (How do usage and length limits work?).
  3. Turn on usage credits. On Pro and Max, your requests continue at standard API rates until you reach your monthly spend limit or your balance runs out (Manage usage credits).
  4. Use a limit reset, if you are offered one. Anthropic gives these occasionally to eligible plans. A reset fills either your session limit or your weekly limit, but your weekly schedule does not change (What is a limit reset?).

How to check your Claude usage

Claude itself gives you three places to look:

  • Settings, then Usage, in Claude. The Plan usage limits section shows progress bars for your session and weekly limits, and when each one resets (Usage limit best practices).
  • The /usage command in Claude Code. Subscribers see plan usage bars and a breakdown of what used them (Manage costs effectively).
  • The usage ring in Claude Desktop, next to the model picker, or the rate_limits fields in a custom Claude Code status line (Claude Code error reference).

See every account from your Mac's menu bar

If you use more than one account, or you want the numbers without opening Claude, Limits Left is a free, open source macOS menu bar app. It shows each account's 5-hour, weekly, and model limits with their reset times. With two or more accounts of one provider, it adds up their weekly quota. It also shows whether you are ahead of or under pace, and forecasts when your weekly quota would reach 0%. It reads Claude usage from endpoints Anthropic has not documented, so treat Claude's own Usage page as the reference. It also covers Codex; see Codex usage limits.

Limits Left is an independent project and is not affiliated with or endorsed by Anthropic.

Frequently asked questions

How many messages do I get on Claude Pro?

Anthropic does not publish a fixed number. Usage depends on conversation length, files, tools, model, and effort level. The pricing page says Pro gives at least five times the Free plan's usage per five-hour session.

When does the Claude weekly limit reset?

At a fixed day and time assigned to your account. It does not move when you start using Claude. Find it under Settings, then Usage.

Does Claude Code have separate limits from claude.ai?

No. On Pro and Max, Claude, Claude Desktop, Claude Code, and IDE use all draw from the same session and weekly limits.

Does switching models help when I hit a limit?

Only for a model-specific limit, such as an Opus, Sonnet, or Fable limit. Switching does not help with the session or weekly limit, because those cover all models.

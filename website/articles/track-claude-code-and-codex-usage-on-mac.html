How to track Claude Code and Codex usage on your Mac

Use Claude's Usage page, the Claude Code /usage command, and the Codex /status command for a quick check; use a tracker app when you want limits for several accounts, history, or cost estimates in one place.

Published October 16, 2026

A Claude Code usage tracker answers one of two questions. How much of my plan's limit is left before I have to stop? Or how many tokens did I use, and what would they cost at API prices? Most tools answer one of these well. This guide covers the built-in checks first, then compares five free, open source trackers for Mac, so you can pick the one that fits how you work.

Product details below come from each provider's documentation and each project's own README, as of October 2026. These tools change often, so follow the links for current details.

What to track: limits or token costs

Plan limits decide whether you can keep working. Anthropic says Pro and Max plans have a five-hour session limit and a weekly limit, and that Claude and Claude Code share the same limits (Anthropic Help Center). OpenAI says Codex limits on Plus and Business plans are counted per five-hour period, that Pro plans currently have no five-hour limit, and that weekly limits may also apply (Codex pricing). For the details of each plan, see how Claude usage limits work and how Codex usage limits work.

Token costs tell you how much work went through the model. If you pay per token with an API key, that is your bill. On a subscription it is only an estimate. Anthropic's Claude Code docs say the session cost in /usage is computed locally at list price and "isn't relevant for billing purposes" for Pro and Max subscribers (Claude Code costs).

If you mostly hit limits, track percentages and reset times. If you want to compare models or projects, or you pay per token, track tokens and cost.

The built-in ways to check usage

You may not need a tool at all. Each provider shows your current usage for the account you are signed in to.

Claude's Usage page

On claude.ai, open Settings > Usage. On Pro, Max, Team, and seat-based Enterprise plans it shows progress bars for your five-hour session and weekly limits, the time left in the session, and when the weekly limit resets (Anthropic Help Center).

The Claude Code /usage command

Type /usage in Claude Code. Subscribers see plan usage bars, activity stats, and a breakdown of recent usage by skills, subagents, plugins, and MCP servers. The breakdown comes from session history on that machine only, so usage from other devices or claude.ai is not included. API users see token counts and an estimated session cost (Claude Code costs).

The Codex usage dashboard and /status command

OpenAI points to the Codex usage dashboard for current limits and reset times. In an active Codex CLI session, /status shows your remaining limits (Codex pricing).

These checks are accurate and free. Their limits are practical: you have to go and look, you see one account at a time, and you see the current state rather than a history.

Usage tracker tools compared

The five tools below are all open source under the MIT license. Two are terminal programs and three are menu bar apps.

CodexBar Menu bar app and CLI Limits, credits, and spend for many providers macOS 14+, Linux

ccusage

ccusage reads the local logs that coding agent CLIs write and turns them into daily, weekly, monthly, and session reports with token counts and costs in US dollars. It supports Claude Code, Codex, and many other CLIs, including Gemini CLI, GitHub Copilot CLI, and OpenCode. It also has a report of Claude Code's five-hour blocks, a status line for Claude Code, per-model breakdowns, and JSON output. Run it with npx ccusage@latest; docs are at ccusage.com.

Suits: people who live in the terminal and want token and cost reports, especially across several agent CLIs. It is the strongest choice here for cost tracking.

CodexBar

CodexBar is a macOS 14+ menu bar app that shows usage limits and reset countdowns for a long list of providers, including Codex, Claude, Cursor, Gemini, and Copilot. It also shows credit balances, spend dashboards for API-backed providers, local cost scans for Codex and Claude, provider status incidents, and widgets. There is a Linux desktop app and a bundled codexbar CLI. Install it with brew install --cask codexbar.

Suits: people who use many AI providers and want one menu bar view of all of them, including spend.

Claude Code Usage Monitor

Claude Code Usage Monitor is a live terminal monitor for Claude Code written in Python. It tracks tokens, messages, and cost within five-hour sessions, can capture Claude Code's official rate limit fields through the status line, and labels each number as official or a local estimate. It adds forecasts, pace, and an opt-in local history that outlasts Claude Code's 30-day log cleanup. Install it with uv tool install claude-monitor or pip install claude-monitor.

Suits: Claude Code users on any operating system who want a live dashboard in a terminal window. It does not cover Codex.

Claude Usage Tracker

Claude Usage Tracker is a native macOS 14+ menu bar app for Claude's five-hour session, weekly, and per-model limits. It manages several Claude accounts as profiles, can switch Claude Code logins between them, and added Codex support in version 3.3.0. It also offers a terminal status line, usage history charts, API usage and cost per profile, notifications, and automatic updates. Its README notes minimal anonymous analytics, a version-only heartbeat. Install it with brew install --cask hamed-elfayome/claude-usage/claude-usage-tracker.

Suits: heavy Claude users with several accounts who want profile switching and lots of display options.

Little Limits

Little Limits is a native macOS 14+ menu bar app, for Apple silicon and Intel, that shows how much Claude and Codex quota is left on every account you add. The menu lists each account's five-hour, weekly, and model limits with reset times. The Home window adds weekly totals across accounts of one provider, whether each account is ahead of or under pace, and a forecast of when your weekly total would reach 0%. A Models page shows how each model behaves in your own work, such as output speed and steps per turn, built from local Claude Code and Codex logs.

The app only reads usage. It stores derived facts, never prompts, replies, or file contents, in a history that stays on your Mac, and it has no telemetry. See what the app stores for the full list.

Where it falls short: it covers only Claude and Codex, it does not estimate token costs in dollars, and Claude readings come from endpoints Anthropic has not documented, so they are experimental.

Suits: people who switch between several Claude and Codex subscriptions and want to see, at a glance, which account has room left and when the next reset comes.

Which one to choose

  • You want a quick check now: Claude's Usage page, /usage in Claude Code, or /status in Codex.
  • You want token and cost reports: ccusage, or CodexBar's local cost scans.
  • You use many AI providers: CodexBar.
  • You want a live terminal dashboard for Claude Code: Claude Code Usage Monitor.
  • You juggle several Claude and Codex accounts and care most about limits: Claude Usage Tracker or Little Limits.

The terminal tools and the menu bar apps do not conflict. You can keep a menu bar app open for limits and run ccusage now and then for cost reports.

How to install Little Limits

With Homebrew, run:

brew install --cask parkerrex/tap/little-limits

Or download the zip file from the latest GitHub release, unzip it, and drag the app into your Applications folder. The app is signed and notarized by Apple.

  1. Open the app. A small gauge icon appears in the menu bar.
  2. Choose Add Claude Account… and sign in to claude.ai in your browser.
  3. Add a Codex account from the app window. This needs the Codex CLI or the ChatGPT desktop app.
  4. Open Show in Menu Bar to pick which accounts get a number.
